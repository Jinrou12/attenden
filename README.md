# Student Attendance System / ប្រព័ន្ធស្រង់វត្តមានសិស្ស

A modern, responsive web-based student attendance tracking system built for Cambodian schools.

## Features
- 📋 Weekly & Daily attendance views
- 📊 Analytics dashboard with charts
- 📥 Excel import/export
- 🖨️ Print-ready reports
- 📱 Fully responsive (Phone + PC)
- 🌙 Dark/Light theme toggle
- 🇰🇭 Full Khmer language support

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Chart.js for analytics
- SheetJS (xlsx) for Excel import/export
- html2canvas for JPEG export
- Lucide Icons

## Getting Started
1. Clone the repository
2. Open `index.html` in a browser, or serve with any HTTP server
3. No build step required!
